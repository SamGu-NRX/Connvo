# Connvo two-peer call eval harness (S0)

Transport-agnostic two-peer call harness for scoring call transports
(`docs/plan/CALL-PLAN.md`, step S0, task `connvo-call-harness-f1`).

- `CONTRACT.md` — the join contract: DOM contract, H/P scenarios (pass
  conditions quoted verbatim), runner/CLI shape, fixtures spec, identities,
  git protocol, baseline.
- `reference/` — eval-only reference transport (local WebSocket signaling),
  registered as `"reference"`, plus named broken variants used for
  self-proof.
- `fixtures/` — generated per-peer media (y4m with peer color + frame-counter
  barcode; wav tones 440/660/880 Hz). Regenerated by
  `node tools/call-eval/scripts/generate-fixtures.mjs`.
- `scripts/` — local backend + identity seeding (`local-backend.mjs`,
  `pnpm call-eval:backend`) and fixture generation.
- `out/` — run outputs (`results.json`, `summary.md`, screenshots, `state.json`).
  Not committed except where the plan requires a committed matrix
  (`self-proof/`).

Run:

```sh
pnpm call-eval:backend   # local Convex + seeded identities + next dev
pnpm call-eval -- --transport=reference --suite=all --seeds=20
```

More detail lives in `CONTRACT.md`; the plan is authoritative where they differ.
